Production Analysis

Watch quality change machine by machine and batch by batch, all the way through the mill line.

Machine-wise & series-wise

Two ways to see production quality

A mill line rarely runs as a single machine — grain moves through cleaners, huskers, sorters, graders and polishers in sequence. TMA supports both views of that reality:

  • ✓ Machine-wise — analyse the output of one specific machine in isolation, sample by sample
  • ✓ Series-wise — analyse a full multi-machine production run as one connected series, from input to output
  • ✓ Every run is tagged by batch / bin-dryer number and process type — Raw or Parboiled

Every machine, on its own terms

A dedicated analysis module for each stage

Different machines do different jobs — so TMA measures each one against the parameters that actually matter for that stage.

Husker Analysis

Measure and monitor:

  • Paddy percentage
  • Broken percentage
  • Shelling degree
  • Brown rice percentage

Tray Separator Analysis

Monitor paddy separation and identify unwanted paddy carryover in rice streams — turning sorting performance into measurable data.

Whitener Analysis

Measure critical parameters, including:

  • Whiteness Index
  • Broken percentage
  • Degree of milling

Polisher Analysis

Evaluate finished grain quality through:

  • Whiteness & Translucency Index
  • Broken, discoloured & chalky percentage
  • Grain-level chalky area analysis
  • Cooking & nutrition prediction

Thickness Grader Analysis

Monitor size separation performance and identify grain carryover between streams:

  • Thin rice percentage in thick rice output
  • Thick rice percentage in thin rice output

Length Grader Analysis

Evaluate separation efficiency and grain composition:

  • Head rice % in broken output, brokens % in head rice output
  • Grain length, width & aspect ratio
  • Detailed broken classification

Sifter Analysis

Measure separation performance and identify product carryover between fractions.

Colour Sorter Analysis

Know what the sorter is removing — and what valuable rice may be going with it:

  • Good rice % in rejects, reject % in good rice
  • Individual chalky & discoloured percentage

Blend & Pack Analysis

Verify final product composition and broken classification before dispatch — so what's delivered matches the intended specification.

Trend over time

Sample-to-sample, all day, every day

Every trial feeds a live, sample-to-sample trend — not just a daily average. Whether you've selected a single machine or a full production series, TMA plots how head rice, brokens and rejections move from one sample to the next, across every day in the selected range, so drift shows up immediately instead of at month-end.
